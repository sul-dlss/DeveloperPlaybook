# AI Coding Tools

Current UIT guidance is documented in [GenAI Tool Evaluation Matrix](https://uit.stanford.edu/ai/genai-tool-matrix) under "AI Coding Assistants & Agentic Development Tools".

While this will continue to evolve, within DLSS AI coding tools can only be used for open-source code (including any public `sul-dlss` repositories).

The only approved AI coding tool that DLSS will pay for is individual [Github Copilot](https://github.com/features/copilot/plans) Pro licenses. See your manager for details on approval / payment. You may use other free or personally funded tools on open-source code.

If you have questions about additional paths for using sanctioned AI coding tools (e.g., via Stanford's AI Playground), consult Julian.

If additional AI coding tools are approved or you are successful with alternate paths for using AI coding tools, please document here.
